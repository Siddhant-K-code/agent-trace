# Offline review worksheet

Review this proposed synthetic change using the files supplied in this folder.
Start with `evidence/bundle.json` if you have the plain evidence view, or
`packet/review.md` if you also have a packet. You can read the underlying
evidence in either view. Do not execute the proposed change or run its checks.

**Case and view:**

**Decision:** accept / reject / request evidence / request changes

**Rationale and pointers:** What supports the stated change? Cite the most
useful file, field, or line. Distinguish what was shown from what was reported.

**Remaining concern and next action:** What, if anything, would change your decision?

**Active review effort (reviewer):** Minutes, if manually recorded; note any
time spent finding or reconciling evidence. Leave blank if unmeasured.

**Active assembly effort (assembler, record separately):** Minutes, if
manually recorded; note collection, preparation, and packaging work. Leave
blank if unmeasured. Do not include this time in review effort.
