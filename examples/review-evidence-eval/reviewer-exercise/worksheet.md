# Offline review worksheet

Review this proposed synthetic change using the files supplied in this folder.
Start with `packet/review.md` if present, otherwise start with
`evidence/bundle.json`. Use the supplied evidence only. Do not execute the
proposed change or run its checks.

**Item (folder name):**

**Decision:** accept / reject / request evidence / request changes

**Rationale and pointers:** What supports the stated change? Cite the most
useful file, field, or line. Distinguish what was shown from what was reported.

**Remaining concern and next action:** What, if anything, would change your decision?

**Review effort (reviewer):** Active minutes spent reading evidence, including
ordinary lookup, and writing the decision. Exclude recovery and assembly.

**Recovery effort (reviewer):** Active minutes spent dealing with missing,
unreadable, or inconsistent supplied files. Note what was affected and
whether you could finish. Requesting evidence in a decision is not recovery.

**Assembly effort (assembler only):** Active minutes spent collecting,
checking, or packaging evidence before handoff. Do not count it as review or
recovery effort.

For each effort field, record `not measured` or leave it blank if unmeasured;
use `0` only if you recorded that no time was spent. Do not count the same
minutes in more than one field.
