# Reviewer exercise reference and manual rubric (v1)

Coordinator only. For packaged sets, match the worksheet to the case using
`assignments.json` after review. Apply the same rubric to both views using the
cited retained evidence. The reference concerns are independently authored,
not producer verdicts.

| Case | Action | Evidence | Remaining concern |
|---|---|---|---|
| Greeting | Accept for the exercise with a rationale, or request a specific independent verification of the greeting or inspection. | Cite `change.input` for `Hi` to `Hello`, `unit.input` for the relevant reported pass at the target head, and `summary.input` for the reported inspection. | Note that capture is partial and neither the check nor the inspection was independently reproduced. |
| Footer | Request a current revision-bound footer-content check and evidence of the required preview. Requesting changes is defensible if it explicitly asks for those two items rather than alleging a code defect. | Cite `change.input` for `Draft` to `Ready`, `format.input` for the current but irrelevant formatting pass, and `intent.input` and `summary.input` for the required preview and lack of a retained observation. | Note that partial capture does not prove the preview was skipped; the reported formatting pass does not validate the footer label. |

Score **action**, **evidence**, and **remaining concern** separately:
`1` if the response meets the corresponding case cell; `0` for an omitted,
unsupported, or contradicted element in a completed review. Equivalent
wording and pointers through the packet back to the underlying source count.
A green check, a coverage label, or the word "accept" alone earns no credit.
Mark an item `unscored` if its worksheet is missing, the reviewer did not
complete it, or unavailable materials prevented a review. Record the reason;
do not treat `unscored` as `0` or silently drop it.

Record active assembly, review, and recovery effort separately. Assembly is
before handoff; review includes ordinary evidence lookup and writing the
decision; recovery is time spent trying to resolve an unexpected problem with
the supplied materials. Record shared assembly effort once at its actual
scope rather than multiplying it by the number of set copies. Mark blank or
unmeasured effort `missing`, not zero. Do not impute effort or infer it from
the decision; record `0` only when explicitly confirmed that no time was spent.

This rubric is for two synthetic exercises only. A real assessment would need
representative cases, a prespecified protocol and effort measurement, and
authorization and consent before collecting human data. Assembly success,
coverage, and reported validation are not human decisions or evidence of time
savings, product usefulness, or ROI.
