# Release notes

1. Read the `## [Unreleased]` section of `CHANGELOG.md`.
2. Group entries under **New**, **Improved**, and **Fixed**. Leave out entries under `### Internal`.
3. Rewrite each entry for users: one sentence, present tense, no issue numbers.
4. Print the notes as Markdown. Do not edit `CHANGELOG.md`.
